# 统计页面方案讨论

生成实现统计页面的PRD，这里只是和你讨论方案，没有我的确定，你不要直接生成文档和修改项目。

## 页面布局

统计页分三个板块：流水排行，流水统计，流水趋势，暂定这三个名字，如果你有更好的想法告诉我。各个板块之间要有间距，并且和页面四周边缘也需要有间距不能紧贴。且各个板块需要有圆角，布局可以参考配置管理也的布局。

## 流水排行

根据流水金额的大小按顺序排列展示流水，默认降序排序。这个板块的目的是方便查看金额在指定时间段的数值情况。

#### 顶部

顶部为筛选区域，根据条件筛选或切换需要展示的流水金额，有五个交互，展示顺序依次为：

1. 最左侧：流水类型筛选按钮，为全部、支出、收入。默认为全部。具体的交互和样式参考"流水页面"筛选区域的类型筛选。但是这里不需要展示"类型"两个字。
2. 第二个：流水类别切换按钮，展示的流水金额类型，有一级和二级，默认为二级。交互及样式参考痛流水类型筛选。注意这个不是筛选，是按分类的形式展示流水。如存在有以下分类的流水：一级：三餐(二级：早餐、午餐、晚餐)，零食饮料(二级：休闲零食、甜品小吃)，数字服务(二级：软件订阅，网络服务)。为一级分类展示形式，则按顺序展示三餐、零食饮料、数字服务；为二级分类展示形式，则按顺序展示：早餐、午餐、晚餐、休闲零食、甜品小吃、软件订阅，网络服务
3. 第三个：流水展示周期切换按钮，分为月和年。按月展示时，列出改月的金额排行情况。按年展示，列出改年的金额排行情况。
