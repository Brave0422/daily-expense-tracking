# 统计页面方案讨论

梳理生成"统计页面"的PRD，这里只是和你讨论方案，没有我的确定，你不要直接生成PRD和修改项目。

## 页面布局

统计页分三个板块：流水排行，流水统计，流水趋势，暂定这三个名字，如果你有更好的想法告诉我。各个板块之间要有间距，并且和页面四周边缘也需要有间距不能紧贴。且各个板块需要有圆角，布局可以参考配置管理也的布局。

假设存在有以下分类的流水：一级：三餐(二级：早餐、午餐、晚餐)，零食饮料(二级：休闲零食、甜品小吃)，数字服务(二级：软件订阅，网络服务)。

### 流水排行

根据流水金额的大小按顺序排列展示流水，默认降序排序。这个板块的目的是方便查看金额在指定时间段的数值情况。

#### 顶部

顶部为筛选区域，根据条件筛选或切换需要展示的流水金额，有五个交互，展示顺序依次为：

1. 最左侧：流水类型筛选按钮，为支出、收入。具体的交互和样式参考"流水页面"筛选区域的类型筛选。但是不需要展示"类型"两个字。
2. 第二个：流水类别切换按钮，展示的流水金额类型，有一级和二级，默认为二级。交互及样式参考流水类型筛选。注意这个不是筛选，是按不同分类的形式展示流水。比如：时间为2026-10，为一级分类展示形式，则按顺序展示三餐、零食饮料、数字服务在2026-10的排行；为二级分类展示形式，则按顺序展示：早餐、午餐、晚餐、休闲零食、甜品小吃、软件订阅，网络服务。注意：收入只有一级分类，类型切换为收入时，强制改为一级分类且无法选择二级分类。
3. 第三个：流水展示周期切换按钮，分为月和年。按月展示时，列出该月的金额排行情况。按年展示，列出改年的金额排行情况。类似流水页面的日/月切换按钮。
4. 第四个：日历按钮，点击出现日期选择器，点击日期则展示选中日期的流水金额。跟"流水页面"类似，日期选择器只能单选。为月展示时，日期选择器只能选择月份，如2026-10，为年展示时，只能选择年份，如2026。
5. 最右侧：排序按钮，根据金额大小排序，金额相同根据id排序，默认为降序，点击切换为升序。

#### 列表区域

1. 列表区域有最大高度，数据过多区域出现局部纵向滚动条
2. 列表中每条数据的布局：左侧为排名序号，接着是分类图标。然后是详细的内容，把分为上下行，上层左侧显示分类名称，右侧显示金额数值，下层为一个进度条，进度条默认为灰色，通过该条流水的金额数值占此次排行榜的总金额的百分比来通过主题色进行填充。最右侧是金额的占比百分比。序号为阿拉伯数字，前三需要有不一样的样式；金额数值为14px，加粗，收入为红色，支出为绿色，不需要带"-"。两者的具体颜色参考流水页面的收入和支出的金额颜色。详情可以参考示例图

### 流水占比

通过饼图展示各个流水金额在该次总金额的占比

#### 顶部

顶部筛选区域，交互和逻辑跟流水排行板块类似，但是没有排序。

#### 饼图区域

通过展示的分类不同，饼图的比较内容也不同。比如：时间为2026-10，为一级分类展示形式，则展示三餐、零食饮料、数字服务在2026-10时间段在总金额中的占比；为二级分类展示形式，则展示早餐、午餐、晚餐、休闲零食、甜品小吃、软件订阅，网络服务，在2026-10时间段总金额中的占比

1. 左侧为饼图目录：颜色，分类名称
2. 右侧为饼图，通过颜色代表分类展示占比，鼠标hover显示流水名称，金额数值，百分比

### 流水趋势

通过条形统计图展示在指定时间段金额的变化情况

#### 顶部

顶部为筛选区域，调整条形统计图的展示形式以及筛选时间

1. 流水类型筛选按钮，为支出、收入。
2. 流水展示周期切换按钮，分为月和年。按月展示时，列出该月的每日总金额，如2026-10，统计图依次展示1日31日的金额。按年展示，列出该年的每月总金额，如2026，统计图依次展示1月~~12月的金额
3. 日历按钮，点击出现日期选择器，点击日期则展示选中日期的流水金额。跟"流水页面"类似，日期选择器只能单选。为月展示时，日期选择器只能选择月份，如2026-10，为年展示时，只能选择年份，如2026。

#### 统计图区域

1. 顶部左侧显示支出/收入总额，下一行显示该时间段的总金额，总金额数字保留两位小数，且需要很大，加粗。总金额数值右侧紧接着显示相比较的涨幅/降的百分比，如果是按月展示，则显示"较上月 ↑/↓ xxx.00%"，保留两位小数。如果是按年展示，则显示"较上年 ↑/↓ xx.00%"，如果是增益百分比，用红色显示，负收益，用绿色显示。如支出如果相比之前增加了，用绿色字体显示，反之用红色。收入相比之前增加了用红色字体，反之用绿色
2. 根据筛选情况展示金额的条形统计图。条形统计图X坐标为时间段，Y坐标为金额数值

## 后端逻辑

此次后端不需要建表，分6个接口，都是查询接口，所有接口都需要userId。

1. 流水排行按月查询接口
2. 流水排行按年查询接口
3. 流水占比按月查询接口
4. 流水占比按年查询接口
5. 流水趋势按月查询接口
6. 流水趋势按年查询接口

### dto

#### 通用接口dto

- 流水类型，type，只能是枚举值，必填
- 流水分类，categoryType，只能是一级或二级，必填

#### 按月查询接口通用dto

- 继承`通用接口dto`
- 按月展示周期，month，格式"yyyy-mm"，必填

#### 按年查询接口通用dto

- 继承`通用接口dto`
- 按年展示周期，month，格式"yyyy"，必填

### 通用响应结构

```ts
data: {
  date: '', // 时间
  type:'', // 流水类型
  total:'', // 流水总数
  totalAmount:'', // 流水总金额
  // 流水列表
  transactions: [{
    id:'',
    category:{
        id:'',
        iconKey:''
        name:'',
        backgroundColor:'',  // 二级分类继承父类背景色
    },
    amount:, // 该条流水的金额数目
    percentage:'' // 该流水占此次总金额的百分比
  }];
}
```
