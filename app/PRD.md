# 移动端主 PRD

版本：v1.0；立项日期：2026-10-14；状态：需求文档已建立，Flutter 工程待生成。

## 1. 项目目标

为 Daily Expense Tracking 增加 Android / iOS 移动客户端，让用户在手机上完成记账、查询、分类与标签管理和收支统计。Web 与后端初版已完成，移动端复用现有业务 API，按手机操作习惯设计页面。

本文件是需求入口和模块索引。生成代码前必须阅读公共约定，再阅读当前模块文档；不能只依据主 PRD 或单个页面说明实现整个项目。

## 2. 已确认的实施基线

| 项目 | v1 要求 |
| --- | --- |
| 工程目录 | 仓库根目录 `app/`；当前仅建立文档，后续在此初始化 Flutter 工程 |
| 平台与语言 | Android、iOS；Flutter + Dart；界面默认简体中文 |

## 3. 首版范围

1. 账户：登录、注册、邮件验证码、忘记密码、修改密码、会话恢复与退出登录。
2. 流水：新增、编辑、删除、按日明细、按月汇总和已有接口支持的筛选。
3. 分类：收入一级分类、支出两级分类、名称与图标维护、删除。
4. 标签：创建、改名、删除、搜索，以及流水中的标签草稿和同名复用。
5. 统计：按月 / 年的分类排行、分类占比和收支趋势。
6. 基础能力：统一请求与错误处理、登录访问控制、移动交互、资源适配和必要测试。

首版不包含预算、账户注销、头像或资料编辑、多币种、附件上传、推送、导入导出、分类拖拽排序、分类重置、归档恢复及任意日期范围查询。后续扩展需单独补需求并确认后端能力。

## 5. 核心用户流程

- 首次启动 → 恢复 Cookie 会话 → 未登录则进入登录页 → 登录成功进入流水页。
- 流水页 → 点击“记一笔” → 输入金额、分类、日期和可选标签 → 服务端保存成功 → 返回并刷新数据。
- 流水页 → 查看日明细或年内月汇总 → 应用筛选 → 查看服务端返回的合计与结果。
- 我的 → 分类 / 标签管理 → 修改配置 → 相关流水选项与统计数据重新查询。
- 统计页 → 独立切换某个板块的收支、周期或分类层级 → 只刷新该板块。
- 我的 → 修改密码或退出登录；退出后清理本机当前账号的业务状态和认证凭证。
