# 07 收支统计

[返回主 PRD](../PRD.md) · [API 契约](09-api-contracts.md) · [移动交互](08-mobile-ui.md)

## 1. 三个独立板块（STAT-01）

统计页提供分类排行、分类占比、收支趋势三个板块，可用子标签切换。每个板块独立保存查询条件与状态；修改某一板块条件只刷新该板块。

| 条件 | 排行 | 占比 | 趋势 |
| --- | --- | --- | --- |
| 收支 | 支出 / 收入 | 支出 / 收入 | 支出 / 收入 |
| 周期 | 月 / 年 | 月 / 年 | 月 / 年 |
| 日期 | 当前选定月份 / 年份 | 独立选定月份 / 年份 | 独立选定月份 / 年份 |
| 分类层级 | 支出一级 / 二级；收入一级 | 同排行 | 无此字段 |
| 排序 | 金额降序 / 升序 | 不提供 | 不提供 |

默认各板块为支出、当前月，分类板块为一级，排行为降序。没有“全部收支”、结余饼图、标签筛选、任意起止日期、服务器分页或统计页的流水增删改。

只加载当前可见板块；切换后按该板块已保留的条件加载 / 刷新。业务写入使数据失效后，可见板块刷新，其他板块下次进入时重查。

## 2. 查询约束（STAT-02）

- 切换到收入自动使用 categoryLevel=1，并隐藏二级选项；不能向后端提交收入二级后等待“自动修正”。
- 切换月 / 年时请求只携带 month / year 之一，保留各周期自己的日期选择。
- 趋势不发送 categoryLevel / order，占比不发送 order；统计接口拒绝多余字段。
- 月份与年份选择器遵守 API 的比较周期边界，不固定为立项日期。
- 快速切换条件时取消旧请求，旧响应不能覆盖新条件；当前板块错误不抹掉另一个板块的有效结果。

## 3. 统计口径：与历史流水不同

统计按 occurredDate 计算完整自然月 / 年，不按 createdTime 或“截至今天”截取。本期与上一期采用相同口径。

当前后端排除以下数据：已归档流水、实际分类已归档的流水、支出父级分类已归档的流水。分类状态取查询时的当前状态，不还原过去的配置快照。

因此分类删除后，历史流水页仍可展示关联信息，但统计金额可能下降。App 必须采用统计接口结果，不能用流水列表在本地重算来“修正差异”。标签本身不作为本页筛选条件。

一级支出统计为有效子分类的汇总；二级为实际子分类，收入为一级。切换层级改变分组粒度，不能重复计算一级与二级金额。

## 4. 分类排行（STAT-03）

- 展示周期、收支方向、总金额、笔数及完整排行列表。
- 列表每项显示序号、分类图标、名称、金额和百分比；二级支出补充父分类名以区分同名分类。
- 排名由响应顺序生成，不按金额字符串字典序排序，不擅自截为 Top 3 / Top 10。
- 金额相同时服从服务端稳定顺序；切换升降序不改变金额与占比。
- 金额条可采用 Flutter 原生进度样式；文案使用接口 amount / percentage。

## 5. 分类占比（STAT-04）

- 使用 fl_chart PieChart 展示分类金额占比，并提供可滚动图例，显示名称、金额和 percentage。
- 点击扇区 / 图例突出当前分类；信息必须能通过触摸和文字获取，不能仅依赖鼠标悬停。
- 同一个 categoryId 在一次结果展示中配色稳定；图表扇区色与分类图标的背景色分开处理，避免多个二级分类继承同色而不可区分。
- 使用原始金额计算绘图权重 / 转换坐标，文案显示后端百分比。四舍五入后百分比合计可能不等于 100%，不强行修改某一项。
- 数据为零 / items 为空时显示空状态，不画虚假的等分饼图。

## 6. 收支趋势（STAT-05）

- 使用柱状图展示 series；月轴为该月全部自然日期，年轴为 12 个月，按返回日期升序。
- 没有金额的位置保留零值；当前月未来日期也按完整周期显示，不删掉后端返回的点。
- 轴刻度可稀疏显示，窄屏支持合理的横向查看；选中某柱展示日期与原始金额。
- 展示本期金额、上一完整周期金额、比较周期和变化状态，不把年比较描述成当年截至今日同比。

| changeStatus | 展示 |
| --- | --- |
| increase | 相比上期增加，方向由状态决定 |
| decrease | 相比上期减少 |
| unchanged | 与上期持平 |
| new | 上期为零、本期有金额，显示“新增金额”，不计算无限涨幅 |

changeRate 为百分比字符串，可为 null；不能只根据正负零判断方向，极小增加 / 减少的比例可能舍入为 0.00。金额和比例文案以服务端精确结果为准。

## 7. 空数据、错误与验收

- 每个板块具备首次加载、刷新、空数据、错误和重试状态；刷新失败保留旧内容时标注失败。
- 空结果仍显示当前周期 / 方向；全零趋势可显示零值轴与“暂无收支”，不渲染错误比例。
- 三个板块条件独立，切换不将另一个板块的参数带入请求。
- 收入固定一级，趋势 / 占比不提交多余条件；图表不自行改变统计口径。
- parent=null、同名二级分类、很多分类、空 items、null changeRate、两期为零和上期为零均正常。
- 原始金额与绘图 double 分开，图表文案不通过浮点数重新求和 / 舍入。
