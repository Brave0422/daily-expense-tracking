# 04 流水管理

[返回主 PRD](../PRD.md) · [标签](06-tags.md) · [视觉](08-ios-design-and-interaction.md) · [API](09-api-contracts.md)

## 1. 页面结构

流水为登录默认 Tab。自上而下为标题与“记一笔”、日明细 / 月汇总分段、周期与筛选入口、总览卡、当前条件摘要、结果列表。整页纵向滚动，结果使用惰性列表，不复制 Web 的固定筛选侧栏。

总览卡以支出为最大金额，收入和结余为次级；淡黄色底承接 Web 风格。合计始终标清“本月 / 本年”，不因筛选改变完整周期总览的含义。

## 2. 日明细（TX-01）

- 首次选择当前自然月；支持月份选择及上 / 下月切换。月份为运行时当前值，不能硬编码示例日期。
- 调用 `GET /transactions/daily`。`totals` 展示完整月支出、收入和结余；筛选有效时另显 `filterTotals` 为“筛选收入 / 支出”。
- 按服务端 days / transactions 顺序展示。日期栏显示“10月12日 周一”、当日收支与折叠按钮，默认展开，可在本次周期内记住折叠状态。
- 每笔左侧分类圆图标，中间分类路径 / 标题、可选标签与备注标记，右侧完整金额。支出 `- ¥42.19` 用绿，收入 `+ ¥1,686.55` 用红。
- 支出展示一级与二级关系；收入 secondary=null，不留空路径。无标题时以分类名为主要描述，不以“null”占位。
- 标签可换行或显示前若干项加数量，点击记录后可查看完整内容；备注不在列表撑成长段。
- 归档分类 / 标签显示“已删除”状态；原关联信息依照返回内容保留。
- 点行进入只读详情 Sheet，显示完整分类、金额、自然日期、标题、标签、备注及编辑 / 删除入口；详情来自当前列表快照，不请求不存在的单笔详情端点。
- 行侧滑可提供编辑 / 删除快捷操作，删除仍须确认，`allowsFullSwipe` 不直接执行删除；详情操作为无障碍替代路径。
- 下拉刷新当前条件。无分页接口，不展示“加载下一页”；可以惰性渲染已返回数据。

当前详情不承诺支持外部深链接。页面恢复后没有快照时回列表重查；确认记录已不可用时关闭详情并提示。

## 3. 年内月汇总（TX-02）

- 调用 `GET /transactions/monthly-summary`，周期为年份；从日明细第一次切入取该明细月份所属年份，之后保留各模式上次选择。
- 年总览和筛选合计分别使用 totals / filterTotals；每月显示接口 expenseTotal / incomeTotal，月份顺序遵从响应。
- 月分组默认展开第一条有结果的月份，其余折叠；展开后按支出一级 → 二级，以及收入一级展示，金额使用接口值。
- 点击支出一级展开子项；收入无伪造二级层。月汇总不提供单笔编辑 / 删除。
- 每个月提供“查看本月明细”，转到对应年月的日明细，仅携带当前汇总的收支、分类、金额条件；此入口不混入之前日明细的标题 / 标签 / 备注筛选，并提示已按汇总条件查看。
- 不在手机上自行聚合全年日明细替代汇总 API，不补造后端未返回的有账月份。

## 4. 筛选面板（TX-03）

使用带导航栏的 Sheet，默认可读高度；内容较长 / 键盘出现可扩展至大尺寸。底部固定“重置”“应用”，有清晰关闭入口。

| 条件 | 日明细 | 月汇总 |
| --- | --- | --- |
| 类型 | 全部 / 支出 / 收入 | 同左 |
| 分类 | 多选；可选支出一级 / 二级与收入一级 | 同左 |
| 金额区间 | 非负元字符串，min ≤ max | 同左 |
| 标题 | trim 后最多 50 字符 | 隐藏且不发送 |
| 标签 | 多选，任一匹配 | 隐藏且不发送 |
| 备注 | trim 后最多 100 字符 | 隐藏且不发送 |

面板编辑的是草稿，应用后才改变查询；取消 / 下滑关闭放弃本次面板修改。重置先清空面板草稿，点击应用后生效，不更改周期。面板上显示已选分类 / 标签数量和当前区间。

每种模式独立保存已应用条件。切换模式首次使用默认筛选，此后恢复本模式条件；“查看本月明细”按上一节显式覆盖。标题、标签、备注在汇总模式完全不参与请求，不能以空字符串 / null / [] 发送。

“全部”省略 type；选支出一级表示其二级范围，按 ID 处理，不同父级同名二级不能合并。可以将层级选择 UI 规范化为“选父级即覆盖子级”以避免重复展示条件；最终 ID 必须来自真实分类树。

历史筛选选项通过 `includeArchived=true` 查询并标识状态，归档选项仍可用于历史查询。选择类型时清理不相容的分类并提示，不按名称映射另一分类。输入无效时保留面板并就近提示。重复键数组的序列化见 09。

## 5. 新增流水（TX-04）

“记一笔”打开全屏原生录入页。顶部“取消 / 新增流水 / 保存”，正文单列，不复刻桌面居中长弹窗。

| 字段 | 要求 |
| --- | --- |
| 类型 | 默认支出，黄色分段切换；切换清空不相容分类，保留金额 / 日期 / 文本 / 标签草稿 |
| 金额 | 大字号、小数键盘，必填正数，最多 13 位整数 / 2 位小数 |
| 分类 | 必填；支出必须选二级，收入必须选一级；选择页展示彩色图标 |
| 发生日期 | 默认本机今天，选择有效自然日期；允许其他有效历史 / 未来日期 |
| 标题 | 可选，最多 50 字符，trim |
| 标签 | 选择已有、新名称草稿、已有标签改名草稿，详见 06 |
| 备注 | 可选，最多 100 字符，多行，trim |

金额键盘附“完成”用于收起；粘贴同样校验，不能截断第三位小数或自动四舍五入后偷偷提交。分类 / 标签子页面保留父表单草稿。

分类加载失败显示重试；没有支出二级时说明“请选择或先创建二级分类”，可进入分类管理后返回表单刷新选项，保留已填内容。不能自动生成分类 / 账单。

保存前校验所有字段，锁定提交并禁止关闭；服务端成功后退出表单、刷新当前上下文及失效数据。如果新增日期不在当前列表周期，提示“已保存到 YYYY年M月”，提供“查看该月”操作，不静默改变用户查询。

写成功后查询失败提示“已保存，列表刷新失败”；超时 / 连接中断结果不明确时保留输入并提示先查列表确认，不自动重新创建。

## 6. 完整编辑（TX-05）

- 从当前明细快照创建独立草稿，不直接绑定修改原列表模型；详情 Sheet 关闭后再打开编辑页，避免模态层层覆盖。
- 类型固定，只读显示；PATCH 绝不带 type。
- 必须提交 `categoryId`、`amount`、`occurredDate`、`title`、`tagIds`、`remark`；空标题 / 备注显式 null，无标签显式 []。
- 原有归档分类可以继续保留；只允许选择新的有效分类。换掉旧归档分类后，它不成为可重新绑定的普通选项。
- 原有归档标签允许保留或解绑，不可改名；新关联不能包含其他归档标签。
- tagNames / tagUpdates 作为本次流水事务提交；标签改名须告知会影响其他相关流水。
- 改到其他月份后重查原条件，记录可能自然离开列表；显示保存位置并提供查看新月入口。
- 其他设备并发修改由现有服务裁决；客户端不假定有版本号 / ETag / 冲突合并接口。服务端拒绝后保留草稿，允许返回重查；不伪称解决并发覆盖。

## 7. 删除（TX-06）

删除确认包含分类 / 标题、日期和完整金额，说明：“删除后不再计入流水；仅此流水使用的标签也可能被删除。”调用 `DELETE /transactions/:id/archive`，不物理清除历史关联。

确认中禁止重复发送，失败保留当前上下文。成功关闭详情并使日明细、月汇总、统计、标签列表与筛选选项失效。不在客户端自己引用计数并推断哪些标签已被归档。当前没有恢复接口，不展示撤销按钮。

## 8. 表单与页面状态（TX-07）

有改动的新增 / 编辑页，点击取消、关闭、任何返回手势都必须经过放弃确认；无改动可直接关闭。子选择页取消只取消子页草稿。长表单与大字体均可滚动至保存及错误字段。

区分“本月暂无记录”和“筛选无结果”；筛选无结果提供重置，正常空月提供记一笔。首次加载骨架不冒充零金额；首次失败提供重试；旧结果保留时必须注明其原周期和“刷新中 / 刷新失败”。

验收覆盖：跨年切月、月汇总钻入、清空所有标签、null 文本、归档关联、改变日期、筛选模式切换、快速请求竞态、保存成功后刷新失败、未知写入结果及未保存返回保护。
