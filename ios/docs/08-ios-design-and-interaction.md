# 08 iOS 视觉与交互规范

[返回主 PRD](../PRD.md) · [五张 Web 原图](00-sources-and-references.md#3-原始截图)

## 1. 设计目标（UI-01）

延续“轻、清晰、明亮”的 Web 观感：浅灰承托白色卡片，黄色表达选中和主操作，数字有明确主次，分类圆图标提供识别。页面不用复杂渐变、大面积阴影或装饰图占据记账空间。

相似度验收分为三层：品牌色 / 收支语义 / 分类图形必须一致；卡片、分组、金额层级与图表形式尽量接近；导航、弹层、选择与手势按 iOS 重新组织。截图是视觉依据，不是要求照搬桌面控件尺寸。

## 2. 语义 Token（UI-02）

浅色值取自当前 Web Token 及页面收支色；深色值是本轮原生适配基线，后续需设备检查对比度。禁止在各 Feature 散落独立色值。

| Token | 浅色基线 | 深色基线 | 用途 |
| --- | --- | --- | --- |
| primary | `#FFE639` | `#FFE639` | 选中、主按钮、趋势柱 |
| primaryPressed | `#DEC500` | `#DEC500` | 按压反馈 |
| primarySoft | `#FFF9CC` | `#383319` | 次级按钮、条件强调 |
| page | `#F4F5F7` | `#111214` | 页面底色 |
| surface | `#FFFFFF` | `#1C1D20` | 卡片、表单区域 |
| groupedSurface | `#F4F5F7` | `#26282C` | 日期 / 月份分组头 |
| textPrimary | `#202124` | `#F3F4F6` | 主要文字 |
| textSecondary | `#70737A` | `#A9ADB6` | 次级文字 |
| border | `#E6E8EC` | `#383B42` | 轻描边、分隔 |
| expense | `#249E68` | `#45C58A` | 支出金额 |
| income | `#E34D59` | `#FF7D86` | 收入金额 |
| danger | `#D54941` | `#FF8075` | 错误、删除 |

亮黄色填充上的文字 / 图标统一用深色 `#202124`，不使用白字。白底小字号的黄色不作为唯一信息载体。分类图标背景采用后端颜色，不以深色主题任意改变分类识别；必要时加边界，文字与状态使用主题 Token。

小字号金额需通过文字对比度检查；浅色下可使用同色相的深色文字变体（支出 `#177548`、收入 `#BA2838`），大号金额和图形保留 Web 基线色。启用系统“增加对比度”时加强文字与分隔边界，继续保持支出绿 / 收入红的语义。

金额色延续 Web“支出绿、收入红”，收入增加带 `+`、支出带 `-`；结余正值用收入色、负值用支出色、零值用中性色，并显示“结余”。总览 / 分类汇总不重复添加交易方向符号。危险动作必须有文字或图标，不仅靠红色。

### 尺寸与字体

| 项目 | 默认规格 |
| --- | --- |
| 页面水平留白 | 16pt，小屏 / 大字体不挤掉安全区 |
| 卡片间距 / 内边距 | 12pt / 16pt |
| 卡片 / 输入 / Chip 圆角 | 16pt / 12pt / 8–10pt |
| 触摸目标 | 至少 44×44pt，视觉小图标通过内边距扩大命中区 |
| 分类图标 | 列表约 32pt，选择项约 40pt；中心白图形保持比例 |
| 页面标题 | 系统 Title 风格，约 24–28pt，semibold |
| 总览主金额 | 约 30–34pt，bold；支持多行 / Dynamic Type |
| 正文 / 行金额 | 约 16–17pt；金额 semibold、等宽数字 |
| 说明与标签 | 默认 12–14pt，使用可缩放文本样式 |

使用系统字体与中文系统字形，不打包 Windows 字体。字号是默认视觉目标，以系统文本样式 / 相对缩放实现。长金额优先独占一行或移动次级指标，不能截为 `¥9,99…`；不通过全局缩小字体应付大内容。

卡片以留白和轻描边分组，阴影很轻或不用。原生导航栏、键盘、日期控件遵循系统行为，品牌主要体现在内容区，不全面重绘系统组件。

## 3. 导航与页面地图（UI-03）

```text
启动恢复
├─ 未登录：登录 → 注册 / 忘记密码
└─ 已登录：底部主导航
   ├─ 流水：日明细 / 月汇总 → 筛选、详情、全屏新增 / 编辑
   ├─ 统计：排行 / 占比 / 趋势
   └─ 管理：分类管理、标签管理、账户安全（修改密码 / 退出）
```

使用原生 TabView，三个入口都有图标和文字，选中状态可结合黄色标记 / 深色文字表达，不能只在白底显示低对比黄色字。每个 Tab 有自己的 NavigationStack。切换保留本会话上下文，退出统一清空。

管理页先给出“配置管理”卡（分类、标签），再给出“账户安全”卡；有可信邮箱才显示，否则显示“已登录”。模板管理和预算不显示可操作入口。关于信息可显示实际构建版本，不增加不存在的资料接口。

| Web 表现 | iOS 适配 |

| 横向多列总览 | 支出主数字，收入 / 结余次行，淡黄卡片 |
| 日明细宽行 | 分类 / 标题 / 标签纵向主次，金额独立右对齐 |
| 年内月分类树 | 月份折叠 + 一级 / 二级层级行 |

| 三列统计卡 | 子分段逐个展示，条件独立 |
| 饼图右侧长图例 | 手机图表下方完整图例，可触摸选择 |

## 5. 主要页面线框（UI-04）

以下是信息顺序，不是固定像素截图。界面文案中的时间与金额为示意，正式界面来自运行时和服务端。

### 流水

```text
流水                              ＋记一笔
[ 日明细             月汇总 ]
〈  2026年10月  〉                 筛选(2)
╭ 本月支出                            ╮
│ ¥4,867.65                           │
│ 收入 ¥14,835.10   结余 +¥9,967.45   │
╰─────────────────────────────────────╯
分类：三餐 等   金额：…          清除筛选
筛选支出 ¥… / 筛选收入 ¥…（有筛选时）
▾ 10月12日 周一        收入… 支出…
  [分类图标] 早餐 · 标题        -¥42.19
             标签 / 备注标记
…
[流水]              [统计]            [管理]
```

手指操作区优先：筛选和日期按钮有完整点击区域，“记一笔”有文字；安全区上方保留足够触摸空间。允许前后周期手势作为补充，但按钮必须始终可用。

### 录入

```text
取消              新增流水              保存
[ 支出                    收入 ]
金额（元）
¥ 0.00                     ← 焦点输入
分类 *             选择二级分类  ›
发生日期 *         2026-10-15     ›
标题               选填
标签               已选 / 添加  ›
备注               多行选填
```

正文可滚动，金额处使用占位而不是已填有效金额。键盘附“完成”，保存位置不被键盘遮挡。分类页支出采用一级选择 + 二级网格 / 列表；空二级明确引导创建。标签选择展示已有 / 新建 / 待改名草稿的区别。

### 统计

```text
统计
[ 排行          占比          趋势 ]
[ 支出  收入 ]   [ 一级  二级 ]（趋势无层级）
[ 月  年 ]    2026年10月          排序（仅排行）
╭ 周期、类型、笔数、总金额              ╮
│ 当前板块：排行 / 饼图与图例 / 柱状图 │
╰──────────────────────────────────────╯
```

筛选可以换行，不能横向挤压金额。饼图与柱图形式跟随 Web；数据文案和触摸选中摘要紧邻图表，不依赖短暂提示。

## 6. Sheet、返回与表单（UI-05）

- 短选择 / 筛选用原生 Sheet，中 / 大高度随内容和键盘适配；长录入使用全屏。复杂编辑可使用导航页，不强制所有动作都变成抽屉。
- 一次只呈现一个顶层模态。详情 → 编辑先关闭详情再呈现编辑；分类 / 标签选择可在录入自身 NavigationStack 内推进，返回后保留父草稿。
- 新增 / 编辑 / 改名表单有修改时，关闭按钮和返回都需放弃确认；对无法可靠拦截的下拉 / 侧滑关闭，禁用直接退出并保留显式取消入口。
- 筛选是短期条件草稿，关闭放弃本次更改；只有应用后改变查询。此规则区别于业务数据表单的放弃确认。
- 提交中禁止重复保存和意外关闭，界面显示进度；成功后才离开，不以动画提前假定成功。
- 删除用确认 Alert / confirmationDialog，目标名称、金额、影响范围可读，不用轻触即可永久消失的叉号。

## 7. 统一状态（UI-06）

| 状态 | 表现 |
| --- | --- |
| 初次加载 | 骨架 / 进度，保留页面结构，不显示假的 0 |
| 正常空数据 | 对应周期说明，流水可记一笔，配置可新增 |
| 筛选无结果 | 显示筛选摘要，允许清除 |
| 首次失败 | 可读错误 + 重试，不显示假数据 |
| 刷新中 / 失败 | 旧内容可保留，标清旧条件及状态 |
| 写入失败 | 当前表单持续展示错误并保留输入 |
| 写入结果不确定 | 提示先查询确认，不自动补交 |
| 会话失效 | 遮挡旧业务、清栈、进入登录并说明 |

轻量成功可使用短时原生风格横幅和适度触感；关键错误必须在当前页面持续可见。触感不能是唯一反馈，尊重系统设置与减少动态效果。

## 8. 可访问性与适配（UI-07）

所有图标按钮有中文名称和选中状态，金额朗读包含收入 / 支出与元单位。饼图提供完整图例替代，柱图提供可访问时间点和金额；排序不只通过箭头颜色表达。

至少检查 375pt 宽紧凑 iPhone、常用约 393pt 宽、大屏 iPhone、横屏和较大辅助字号。卡片允许自然增高，分段控件必要时改纵向选项，不全局锁定字体缩放。适配状态栏、刘海、底部手势区与键盘；iPad 专门多栏优化不作为首版阻塞，但可运行布局不能崩溃。

浅色为视觉对照主基线，深色检查所有页面与弹层的可读性；不能只把背景反转而忽略表单 / 图表 / 标签。弱化装饰、保留文字和符号，避免仅靠收支颜色识别方向。

## 9. 视觉验收清单

UI-01–07 均须有模拟器 / 真机截图证据：流水日明细、月汇总、录入和键盘、筛选、分类及图库、标签草稿、三类统计、认证与管理页。核对主黄、卡片留白、完整金额、分类图形、收支配色、原生导航和无障碍。截图不得以 Web 缩图或 Flutter 画面替代。
