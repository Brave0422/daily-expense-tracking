# 07 收支统计

[返回主 PRD](../PRD.md) · [视觉](08-ios-design-and-interaction.md) · [API](09-api-contracts.md)

## 1. 页面与独立状态（STAT-01）

统计 Tab 顶部使用“排行 / 占比 / 趋势”子分段，一次展示一个板块；板块内白卡、总金额、筛选和图表延续 Web。避免把桌面三列缩小塞入一屏。

| 条件 | 分类排行 | 分类占比 | 收支趋势 |
| --- | --- | --- | --- |
| 收支 | 支出 / 收入 | 独立 | 独立 |
| 周期 | 月 / 年 | 独立 | 独立 |
| 日期 | 所选月 / 年 | 独立 | 独立 |
| 分类层级 | 支出一级 / 二级；收入一级 | 同左 | 不提供 |
| 排序 | 金额降序 / 升序 | 不提供 | 不提供 |

首次默认排行；每个板块首次默认当前月、支出；排行和占比默认二级分类，排行默认降序，与当前 Web 一致。收入切换后强制一级，二级禁用并说明“收入仅一级”；切回支出恢复该板块上次支出层级。

各板块保存各自条件、加载、结果与错误，切换不复制其他板块条件。只加载可见板块；业务写入后可见板块刷新，其他板块标记失效，进入时重查。

## 2. 周期和请求（STAT-02）

手机上明确显示“2026年10月”等当前周期，可采用月 / 年分段及日历按钮，保留 Web 的黄色选中态，但不要求复用难理解的纯图标切换。

- 月切年保留年份；每个板块独立记忆每年最后选中月，年切月优先恢复；无记忆时当前年用当前月，其他年用 12 月。
- 选择器只选月或年，不提供任意起止日期。月可选 1000-02 至 9999-11，年可选 1001 至 9998；边界转换若目标超出范围，提示选择有效周期，不发送非法请求。
- 收入 / 层级联动完成后仅发一个合法请求；排行发送 order，占比不发送 order，趋势不发送 order / categoryLevel。
- 本页不提供 type=all、标签、分类 ID、金额区间、标题 / 备注筛选或分页。
- 快速切条件取消旧请求并校验最新序号；旧结果若保留过渡，必须同时标识旧条件与“刷新中”，不能把旧金额标成新周期。

## 3. 统计口径

按 occurredDate 查询完整自然月 / 年，当前月也不截成“截至今天”。上期为上一完整自然月 / 年，一月跨年比较上年十二月。

当前统计排除已归档流水、实际分类已归档的流水、支出父分类已归档的流水。分类状态使用查询时当前状态；标签状态不作为本页筛选。一级支出是有效二级分类的汇总，收入为一级；切粒度不重复算父子。

历史流水查询保留归档分类关联，因此历史总览与统计可能不同。iOS 采用各自接口结果，可在说明中写“统计不包含已删除分类下的流水”，不能拿历史列表在本地重算并覆盖统计。

## 4. 分类排行（STAT-03）

- 显示已加载周期、方向、分类层级、总金额和 transactionCount。
- 每行是连续排名序号、分类圆图标、名称、金额、百分比；前三按当前展示顺序轻强调，升序时代表金额较小的前三。
- 默认只显示分类自身名称以接近 Web；当前结果存在同名二级时补充父级作次级信息，VoiceOver 始终可读父级关系。分类始终按 ID 识别。
- 保持接口顺序，金额相同由服务端顺序决定；不在手机按字符串排序，不擅自截 Top 10。
- 金额两位小数、不带行金额正负号，支出绿 / 收入红。百分比使用接口 percentage，添加 `%`。
- 保留 Web 的单行排行表达，不增加进度条、统计下钻、详情箭头或“查看全部”假入口；大字体允许多行排布。

## 5. 分类占比（STAT-04）

使用 Swift Charts `SectorMark` 绘制实心饼图，与 Web 图形语义一致。窄屏自上而下为总金额、图表、选中摘要、完整图例；大屏可并排图表和图例。

- 扇区绘图权重来自原始 amount 数值，仅绘图阶段转换；文字金额和 percentage 使用服务端精确字符串。
- 图例覆盖全部 items，显示颜色点、分类名、金额 / 占比；不擅自合并“其他”或隐藏小额分类。
- 稳定配色按 categoryId 映射，跨周期、板块切换和顺序变化不改变同一分类颜色；不用 Swift 随机化 hashValue 作为跨启动稳定映射。
- 扇区色独立于分类图标背景，同父级子分类也应可区分。图例、扇区、选中状态颜色一致。
- 点按扇区 / 图例突出对应分类，在图表旁固定的摘要区显示名称、原金额、百分比；长名称可展开，浮层不遮挡关键金额。
- 小扇区可通过图例选择，VoiceOver 可逐项读取。触摸后不要求跳转流水，因为无统计下钻契约。
- items 为空或总额为零显示空态和 `¥0.00`，不画假 100% 扇区。百分比舍入后不合 100% 时不强行修改某项。

## 6. 收支趋势（STAT-05）

使用 Swift Charts `BarMark` 绘制黄色竖向柱状图。顶部显示本期总额、上一完整周期金额及“较上月 / 较上年”变化。

| changeStatus | 文案 | 表现 |
| --- | --- | --- |
| increase | 较上月 ↑ 25.00% | 显示 changeRate 绝对值，支出绿 / 收入红 |
| decrease | 较上月 ↓ 25.00% | 不同时显示负号与下降箭头，支出红 / 收入绿 |
| unchanged | 较上月持平 0.00% | 中性色 |
| new | 较上月新增 | 不显示 100%、Infinity、NaN 或伪造比例 |

年周期将“上月”换为“上年”。方向依据 changeStatus，不能依据舍入后可能为 0.00 的 changeRate 猜测；两期为零是 unchanged，本期为零上期有金额是 decrease 100.00%。配色延续 Web，不把支出涨跌解释为投资收益。

- 月图保留 28 / 29 / 30 / 31 个完整自然日，年图固定 12 个月；无金额位置保留，未来日期也不删。
- 手机通常在可用宽度内绘制全部时间点，轴标签可稀疏；较窄 / 大字体可横向查看，但不能丢点。绘图区建议高 240–300pt。
- 点按 / 横向拖动选柱，摘要显示完整日期 / 月份和原金额，触摸操作不影响页面正常纵向滚动。
- 全零时保留完整时间轴与可读默认 Y 轴；零值本身不绘制假高度。
- Y 轴可使用万等缩写，顶部和选中金额保持完整值；不根据图表浮点坐标重新求总额。

## 7. 状态与验收（STAT-06）

每个板块分别支持骨架、正常、空、首次失败、刷新失败和重试。重试保留当前条件，只刷新当前板块；首次失败不伪造零金额。刷新失败保留旧数据时标记其原周期、方向和层级。

验收包括：默认二级、收入一级联动、板块条件独立、各端点参数白名单、归档排除、同名分类、完整时间轴、跨年上期、两期零值 / 新增 / 涨跌、极小比例舍入、很多分类、稳定配色、长名称与 VoiceOver、触摸图例 / 柱图、旧响应竞态。

原生图表行为依据 [Apple Swift Charts 交互资料](https://developer.apple.com/videos/play/wwdc2023/10037/)；具体展示口径由本模块和当前服务实现约束。
