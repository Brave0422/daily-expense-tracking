## 4. 必要的自动化验证

后续在工程中编写能验证实际边界的测试：

- 金额：0 拒绝、0.01、13 位整数上限、第三位小数、前导零、粘贴符号、区间比较、总额超 Int64 的安全处理；不能由 Double 格式化回请求金额。
- 日期：闰年、月末、跨年、时区变化、当前月完整未来时间点；OccurredDate 来回不跨天。
- 请求 / 解码：重复键数组、汇总没有日专用字段、统计严格白名单、PATCH 显式 null / []、void 缺 data、nullable secondary / changeRate。
- 会话：并发 401 只刷新一次、迟到旧 Token、每请求最多一次重放、刷新 401 与 5xx 区分、轮换 Cookie 保存失败、退出 / 新身份阻止旧 Cookie 回写。
- Cookie：host / path / Secure / 到期、当前环境隔离、删除 Cookie、多个 Set-Cookie、Keychain 读写故障。
- 标签：新名称 / 改名取消无写入、复用必须确认、移除同时取消 tagUpdates、归档项只保留 / 解绑。
- 统计：二级默认、收入一级、同名 ID、跨周期稳定配色、null 涨幅、两期零值 / 新增 / 下降 100%、完整月日 / 年月轴。

可通过可注入 URLSession / URLProtocol 和 CredentialStore 测试替身控制响应顺序与故障；正式依赖必须指向真实实现。不要为每个布局常量写镜像测试；UI 测试聚焦关键可用流程和风险。

## 5. 真实后端闭环

使用独立开发 / 测试账号，不使用真实个人账本。开发固定验证码仅用于专用开发服务，不改生产验证规则。每轮记录本轮创建的分类、标签和流水 ID，按已有归档接口清理测试业务；当前没有账户物理清理接口，测试账号与归档历史可能保留，需在记录说明。

必须走通：注册 → 登录 → 创建支出父 / 子分类与收入分类 → 标签配置 → 带新标签 / 改名草稿的流水保存 → 筛选 / 明细 / 汇总 → 三类统计 → 完整编辑清空标签和文本 → 归档配置后的历史与统计差异 → 删除流水 → 修改 / 重置密码 → 重启恢复 → 退出。

Web 新增 / 改名后 iOS 刷新可见，iOS 写入后 Web 刷新可见。跨端一致性以服务端结果为依据，不能只比较客户端自己的缓存。

## 6. iOS 平台与视觉验收

| 场景 | 必须观察的行为 |
| --- | --- |
| 最低 iOS 17 与实施时当前稳定系统 | 所有选用 API 可运行，导航 / Sheet / 图表可操作 |
| 模拟器 + 至少一台真机 | 网络、Keychain、重启恢复、Secure Cookie、键盘与手势 |
| 375pt 宽、常用 / 大屏、横屏 | 无溢出，长金额完整，卡片与按钮可访问 |
| 大字体、VoiceOver、减少动态效果 | 标题 / 金额可读，控件可聚焦，图表有完整替代信息 |
| 浅色 / 深色 | 卡片、表单、图表、标签、错误及选中状态清晰 |
| 弱网、断网、5xx、写后刷新失败 | 输入保留，不误退出，不自动重复写 |
| 表单侧滑返回 / 下拉关闭 | 未保存改动不被绕过丢失，有明确取消路径 |
| 退出期间迟到请求、切换账号 | 不回写上一身份，不通过返回暴露旧数据 |
