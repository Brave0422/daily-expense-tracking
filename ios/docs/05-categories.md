# 05 分类管理

[返回主 PRD](../PRD.md) · [流水](04-transactions.md) · [API](09-api-contracts.md)

## 1. 入口与层级（CAT-01）

管理 Tab → 分类管理。顶部为支出 / 收入分段，右上“新增”；下方是白色分组卡片和分类圆图标。支出一级可折叠，二级缩进显示，默认折叠；收入仅一级。滚动和展开状态在本次会话、对应类型内保留。

调用 `GET /categories/getUserCategories?type=...`，展示有效分类，保持后端顺序；配置页不把已归档项作为可编辑对象，不实现拖拽排序或重置。切换收支后取消旧请求并防止结果错位。

| 场景 | 层级要求 |
| --- | --- |
| 收入管理 | 只创建一级，不能选择父类 |
| 支出管理 | 一级 / 二级；二级父类必须为当前用户有效支出一级 |
| 流水录入 | 支出绑定二级、收入绑定一级 |
| 历史筛选 | 可选择一级支出表示子类范围，允许标注后的归档项 |

## 2. 新增与编辑（CAT-02）

新增按钮先选择“新增一级 / 新增二级”；收入直接进入一级表单。一级行菜单可“新增二级”并预填父类。新增表单采用 Sheet / 独立页面，显示类型、层级、父级（如有）、名称和图标；有保存 / 取消及未保存保护。

- 名称 trim 后必填，最多 50 字符；同类型同父级范围内的有效分类不能重名。其他父级同名二级合法，以 ID 区分。
- 图标来自 `GET /categories/getAllIcons`，提交真实 `iconKey`；图标库尚未加载时保留草稿并阻止无效保存。
- POST `/categories/create` 提交 type、name、iconKey，二级额外 parentId。
- 编辑只提交 POST `/categories/update` 的 id、name、iconKey。类型、层级、父类只读，不提供移动分类 / 改变类型。
- 成功后重新获取分类树与相关读取；当前写接口无完整实体返回，不能在本地捏造新 ID。
- 服务端重名 / 父类归档 / 图标失效等错误保留输入，允许修正；写入超时结果不明时先查列表。

从记账页进入新增分类时，表单父页面保留金额、日期、文本与标签草稿；完成后重查选项，由用户明确选择分类，不因同名自动绑定。

## 3. 图标资源（CAT-03）

Web 图标源见 [分类资源](../../web/src/assets/icons/categories/)，现有中心图案共 110 个。服务端返回 iconKey 与最终 backgroundColor；二级背景继承一级，由服务端推导，不允许用户编辑颜色。

后续工程生成阶段：

1. 为全部有效 iconKey 建立 Asset Catalog 映射，分类中心图形转换为适用 iOS 的本地矢量 PDF 等原生资源。
2. 分离 Web SVG 的圆形背景与白色中心图案，SwiftUI 绘制圆形背景并显示中心图形，避免双层背景、丢失白色或继承 CSS 失效。
3. 一级使用接口返回背景色；二级也直接使用最终颜色，不能因为换图标改成图标默认色。
4. 通用操作图标用 SF Symbols；分类图标保留现有语义与图形，不用任意 SF Symbol 全量替换。
5. 未知 iconKey 用通用占位，不崩溃，不猜测远程 URL；新图库包含未打包 key 时仍可识别未知状态，不静默显示成另一分类。
6. 随转换资源保留 [第三方许可](../../web/src/assets/icons/categories/THIRD_PARTY_NOTICES.md)，维护源 key 与输出文件映射以便复查。

图库为可滚动网格，选中项显示黄色边框 / 勾选，同时预览当前父级背景。无需给 iOS 提供 CSS、Iconfont Symbol 运行时或 Flutter SVG 插件。

## 4. 删除与历史（CAT-04）

行菜单 / 侧滑打开删除确认，显示当前分类名并说明：历史流水仍保留关联显示；该分类相关记录会被统计排除，统计金额可能改变。

- 调用 `DELETE /categories/:id/archive`，界面叫“删除”，实现是归档。
- 一级分类仍有有效二级时，当前后端拒绝删除。客户端可提前提示“请先删除二级分类”，最终以后端校验为准。
- 不自动循环删除子类，不宣称级联成功；用户需要分别处理子类。
- 成功后刷新分类配置、流水选择 / 筛选、历史展示和统计。不能删除分类时顺便调用流水删除。
- 历史详情与编辑可保留原归档分类，新的流水不能绑定归档分类；没有归档恢复入口。

## 5. 状态与验收

空列表提供新增；支出一级无子类时显示“暂无二级分类”，录入选择器不把该一级当成可保存项。首次错误有重试，刷新错误明确保留旧结果，提交过程中禁止重复操作。

CAT-01–04 验收覆盖：收入禁止二级、支出三级不可达、同父级重名、不同父级同名、父类并发归档、编辑固定层级、未知图标、继承色、一级有子类拒删、取消不写入、删除后统计与历史显示口径不同。
