# 06 标签管理与流水草稿

[返回主 PRD](../PRD.md) · [流水](04-transactions.md) · [API](09-api-contracts.md)

## 1. 两种写入边界

| 模式 | 用户确认的含义 | 写入时机 |
| --- | --- | --- |
| 管理 → 标签管理 | 直接维护全局标签 | 确认后调用标签增改删接口 |
| 流水录入 → 标签 | 维护当前未保存流水的标签草稿 | 保存流水时通过 tagIds / tagNames / tagUpdates 一并事务提交 |

选择器复用组件时必须显式传入模式，不能在流水中点击“完成”就偷偷创建或改名全局标签。当前草稿仅驻留当前会话内存。

## 2. 标签配置（TAG-01）

管理页提供搜索、新增、列表项编辑 / 删除。视觉使用 Web 的轻量圆角标签及数量信息；手机可采用单列管理行，避免小尺寸删除叉号造成误触。行菜单和文字操作均有可访问名称。

- 列表调用 GET `/tags`，按接口顺序显示有效标签。
- 名称 trim 后非空，最多 50 字符，同用户有效标签不能重名。
- 新增 POST `/tags`；改名 PATCH `/tags/:id`，保持原 ID。
- 改名确认说明“会影响使用此标签的其他流水”，不能把改名解释为仅修改当前显示。
- 删除确认后 DELETE `/tags/:id/archive`；说明历史关联保留，标签不再用于新绑定。删除标签不删除流水。
- 成功后重查当前列表 / 搜索，保留关键词，并使流水的标签选项 / 历史显示失效。
- 失败保留输入；无返回实体的成功写入需重新查列表，不伪造 ID 或更新时间。

## 3. 服务端搜索（TAG-02）

关键词 trim 后非空用 GET `/tags/search?key=...`；最多 50 字符。清空时用 GET `/tags`，不发送空 key。建议 300ms 去抖，取消旧请求并验证序号 / 身份代次。

搜索无匹配显示“没有匹配标签”，查询失败提供重试，不能混作无结果。不只过滤已经渲染的一部分本地标签。增改删后保持当前关键词重查，改名后不符合关键词的项自然离开结果。

## 4. 流水选择与新名称草稿（TAG-03）

标签选择 Sheet 包含已选区、关键词搜索、已有结果和“使用此名称”操作；小屏可扩展为大尺寸。底部“完成”只回填父表单，不写数据库。

1. 选择已有有效标签，以真实 ID 去重；已选项有勾选状态。
2. 输入新名称时先校验，再调用只读 GET `/tags/check-name?name=...`。
3. 返回 null：添加到本地 tagNames 草稿，不 POST `/tags`，不生成业务 ID。UI 临时 key 只用于界面，不能发送为 tagId。
4. 返回同名有效标签：展示“已有同名标签，是否复用？”及名称；用户确认后加入其 ID，取消不自动合并。
5. 同名标签已选 / 草稿已有同名项时提示并阻止重复。
6. 查询结束前用户改变输入或关闭面板，迟到查重结果不能添加旧名称。

保存流水时发送已有 tagIds 与新 tagNames，服务端事务负责真实创建。查重后若另一设备创建了同名项，最终保存错误保留草稿并提示处理，不自动改绑定另一 ID。

## 5. 改名草稿（TAG-04）

- 对已选有效标签提供改名操作，保留原 ID；只修改本地名称并记录 `tagUpdates: [{id, name}]`，不提前 PATCH 标签接口。
- 告知该改名会影响其他相关流水；在草稿列表用“待保存改名”标识，防止用户误认为全局已生效。
- tagUpdates 中的 id 必须仍在 tagIds；用户移除该标签时同时移除对应改名草稿。
- 新名称与另一有效标签冲突时提示，不把原 ID 替换为另一标签。
- 新建 tagNames 草稿改名只是替换名称，不发 tagUpdates。
- 取消整个流水时，所有新建 / 改名草稿一并丢弃，不残留全局标签变化。

标签子面板的“取消”撤销本次子面板更改；“完成”合并回父草稿。整个流水保存才代表真正持久化。

## 6. 归档、解绑与流水删除（TAG-05）

编辑历史流水时允许保留原有归档标签，显示“已删除”，也可移除；归档标签不可改名，不得新增绑定其他归档标签。普通新选择结果仅含有效标签。

在流水中移除标签只是解绑，不能调用全局归档端点。删除流水可能让没有其他有效流水引用的标签一并归档，具体结果由服务端决定，成功后重查标签及历史选项。

## 7. 验收

TAG-01–05 验收必须验证数据库副作用：管理确认立即持久化；流水标签完成后尚未写入；取消流水无新标签 / 改名残留；保存流水时原子生效；查重同名需明确复用；取消子面板恢复原父草稿；移除只解绑；归档项只可保留 / 移除；快速搜索与查重迟到不污染当前输入。
